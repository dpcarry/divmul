# 截位近似文献与测量审查

日期：2026-09-05。独立实验，不修改正式 RTL、论文或 canonical PPA CSV。

## 结论与证据边界

简单截位加补偿得到很好的平均误差，不需要用测量错误才能解释。但这不能推出其普遍支配近似算术，也不能推出相关论文有学术不端。当前证据支持三个同时成立的判断：

1. 精度缩减本来就是强基线，截位和补偿也不是新概念。
2. 我们在归一化尾数、均匀独立输入、低精度目标上的实验，有利于非常小的精确内核。
3. 有些历史比较确实存在配置标签或比较范围问题，必须修正解释，而不是回避强基线。

这里不是“所有本地论文已逐字读完”或“全网文献已搜尽”的声明。`inventory.json` 是 research 根目录的 22 个 PDF 文件清单和 SHA256，不是 22 篇独立算术论文，更不是整个 workspace 的递归文献清单。存在同题不同副本、会议/期刊版本、两篇医学公平性论文和用户草稿。OAM 文本提取存在字体乱码，不能把提取成功当作逐式阅读成功。

本轮完成 47 个公式配置乘 5 种输入分布，共 235 行误差结果。不是 235 次 RTL 综合。已有 RTL/门级检查来自此前独立审查，本轮重新检查了实现与 PASS 日志，没有重新运行这些 ModelSim/DC/PT 流程。

## 一、为何简单方法可以很强

令归一化有效数 x,y 属于 [1,2)，保留 b 个小数位，h=2^(-b)。半步重构为

    Q(x) = floor(x/h)*h + h/2.

这不是普通 round-to-nearest：它不读取被丢弃的尾数，也会改变已经恰好落在网格上的数。对连续均匀分布，每个 bin 的均值正好是其中点，故半步重构有很强的统计依据。离散 FP32 网格的严格 bin 均值比连续中点低半个原始 ULP，不能声称两者严格相等。

写 ex=Q(x)-x、ey=Q(y)-y，则

    Q(x)Q(y)-xy = y*ex + x*ey + ex*ey.

由于 x,y 被限制在 [1,2)，灵敏度有界。独立连续均匀输入下，给定两个 bin 后，E[xy|bins]=E[x|bin_x]E[y|bin_y]，所以中点的精确乘积是仅使用这些 bin 信息时的 MSE 最优估计。这个结论既不是 MRED 最优性定理，也不适用于任意相关/非均匀输入。

还可以完全独立于 RTL 推导：

    RMSE_midpoint_product = sqrt(7*h^2/18 - h^4/144).

OAM 理想中点平面为 -kx*ky+ky*x+kx*y=xy-rx*ry。这里 rx*ry 是被省略的误差项，不是我们 RTL 额外计算的一项。cell 边长 d=2^(-L) 时，独立均匀输入下

    RMSE_OAM_plane = d^2/12.

例如 b=3 时，前者约 0.07794；OAM L0 后者为 0.08333。简单乘法略好完全符合解析计算。选择 b=2L+3 时，两种 RMSE 都大致每级下降四倍。此配对仅为说明误差数量级，不能表示面积相同。

除法的相对误差满足

    (Q(x)/Q(y))/(x/y)-1 = (ex/x-ey/y)/(1+ey/y).

分母有效数不接近零是关键。FP32 的极小实数主要由指数承担；只要不触发输出溢出/下溢，同样指数缩放会在相对误差中消掉。但绝对 RMSE 不具有这种尺度不变性。

半步补偿不保证除法无偏。给定两个独立连续均匀 bin，商的条件均值是 mx*ln(y_hi/y_lo)/h，而不是 mx/my。不能把 MUL 的条件均值结论直接搬到 DIV，也不能认为校准倒数系数能对每个输入精确抵消截位误差。

## 二、我们实际的简单除法还缩减了商精度

证据：`../input_trunc_bias/direct.v`。

    a = {1'b1, retained_fraction, fixed_half_bin_bit};
    F = BITS + 2;
    quotient = (a << F) / b;
    q23 = {quotient[F:0], zeros};

`/` 仍是精确整数除法，但作用于缩减后的整数操作数，且只生成有限精度的商；后面补零不是恢复丢失信息。它不是完整精确 FP32 除法器，也不是只截输入、商保持全部精度的实验。面积降低不能全部归因于输入截位。

新的独立公式计算区分了无限精度实数商与 F=b+2 的向下截断商：

| b | 输入半步重构后实数商 MRED | 再截商 MRED |
| --- | ---: | ---: |
| 3 | 2.936884% | 3.291355% |
| 5 | 0.734622% | 0.828488% |
| 7 | 0.182494% | 0.206202% |
| 9 | 0.045915% | 0.051807% |

因此后续真正公平的强基线需要把输入位数与商输出位数作为两个独立变量，而不是把 F=b+2 当作唯一实现。还应包含 floor、half-bin、nearest rounding，并明确舍入发生在哪一级。

## 三、论文到底在研究什么

| 工作 | 本次核对到的内容 | 与简单窄精度内核的区别 |
| --- | --- | --- |
| Hashemi 等 2016 dynamic divider | 选择有效高位后使用较窄精确除法器 | 对整数动态范围需要 LOD、选择和移位；dynamic 一词不能自动等同运行时精度端口 |
| Jiang 等 2019 adaptive divider/square root | 归一化、缩窄精确内核，并处理整数结果范围 | 整数输入范围和溢出处理不同于已归一化 FP 尾数 |
| TruncApp | 输入截位、按位取反等构造近似倒数，再精确/近似乘法 | 不是“缩窄后仍用精确除法”的同一个算法 |
| FaNZeD | Sec. 5/6.1/6.2：近零误差偏置补偿；精度缩减；含 rounding 与不含 rounding 的精确 FP 基线 | 不只比较平均绝对误差；已讨论传统 precision scaling 的强基线 |
| PACE 期刊版 | Sec. 5.3 截差值 z；Sec. 6.1/Fig. 8 比较截位 PACE 与截位 DW；Sec. 6.2 比较不额外截位的版本 | 自身也研究截位；correction 结构与 runtime 的价值不能用一个 fixed 点替代 |
| PLSAD | Eq. 14 八平面、近似加法；FP32 实验明确将输入尾数截到 10 位 | 本来就是平面近似与位宽缩减的组合，不是无截位 FP32 高精度内核 |
| FPD2D | Eq. 6/11-17：二维分区、最小化 MRED、整数系数量化优化；硬件中截低位并合并乘加 | 与“局部平面+位宽优化”非常相关，不能仅与其未经优化的理想平面比较 |
| CADE | 可编程误差修正表与可配置精度 | 配置表/运行时能力是额外目标和代价 |
| SAADI-EC | Taylor 项逐步累加、乘法器复用、截位、误差补偿 | 迭代次数影响延迟/能量；与单周期组合 fixed 单元不是同一执行合同 |
| ILAFD | 近似倒数、多个误差补偿值、迭代对数乘法；FPGA 目标 | 迭代和 FPGA 资源不能用 ASIC 单次组合面积全面评价 |
| LEAD | 指数函数级数近似，局部硬件复用；文中描述两周期数据流 | 不能把本地组合展开版本等同作者两周期面积和延迟 |
| QIAD | 二次插值倒数及乘法式除法 | 更高阶逼近是另一误差/成本选择；本轮未完成逐式独立复现 |
| SIMDive / RAPID | SIMD、多精度及 FPGA 算术目标 | 本轮仍需进一步逐段核查；不据此新报作者 runtime PPA |
| OAM | 理想平面已独立模拟；原作者 correction RTL 的已有对比另有记录 | 本轮不能用自己重写的 correction 链代表作者部分积/压缩树实现 |

FPD2D 的局部坐标减去 tile 左下角，不是减去 cell 中点的有符号 centered residual。两者都能利用 dyadic 分区位编码；不能因为存在局部坐标，就说它与我们的 centered-residual 实现完全相同，也不能说局部坐标/系数优化是我们首创。

外部原始来源：

- [DATE 2017: The Hidden Cost of Functional Approximation Against Careful Data Sizing](https://past.date-conference.com/date17/conference/session/3.4)：已明确提出必须与认真选位宽的传统截位/舍入比较。本轮可访问官方摘要，全文 PDF 获取失败；不把摘要当成全文阅读。
- [Static-segmented FP multiplier, Electronics 2022](https://www.mdpi.com/2079-9292/11/19/3005)：尾数分段、较小内核、截位和误差补偿已有直接相关工作。与本例不完全同构；其物理流程和 pipeline 也不同。
- [TruncApp 原论文, DATE 2017](https://past.date-conference.com/proceedings-archive/2017/pdf/0656.pdf)：截断有效数与近似倒数相乘。
- [FPD2D](https://doi.org/10.1109/TCSI.2024.3447830)；[PLSAD](https://doi.org/10.1109/TCSI.2024.3425538)。本地 PDF 提供了具体公式与实现章节。

## 五、分布反例与测量证据

新公式实验 grid8 是 x,y=1+i/256 的全部 65,536 对。当 b=9 时这些输入原本完全可表示，half-bin 仍把每个输入向上推 h/2，造成不必要的误差：

| MUL 公式 | 均匀随机 MRED | grid8 MRED |
| --- | ---: | ---: |
| b9 半步重构精确乘 | 0.045889% | 0.135617% |
| OAM 理想 L3 | 0.047139% | 0.047217% |

普通 nearest 重构在该 grid 上不会改变输入。故这说明的是 half-bin 方案依赖分布，不是所有截位/舍入方法都失败。同样，OADM 的补偿和校准也需要分布外验证。

旧的实际 RTL 独立审查也发现类似反转，见 `../input_trunc_bias/audit/README.md`。其 275,536 对/设计数据包含独立随机、网格和安全指数输入；七个 direct 配置与独立整数参考逐位一致。`../input_trunc_bias/results/rtl_check.log` 与 `gate_check.log` 各有 21,129 vectors per DUT 的 PASS。本轮检查这些文件，并未重新仿真。不能由此证明全域正确，但没有发现支持“简单方案误差低一定因为测试算错”的证据。

必须纠正的历史标签：338.40/708.12 um^2 的两个 PACE 点是先截输入再相减，不能称为 Sec. 5.3 差值截位的复现。后续正确范围的重建在 `../pace_difference_truncation/`。同理，本地自行重写 correction 链的 PPA 不等于原作者 GitHub 压缩树架构的 PPA。

## 六、站在审稿人角度

真正的风险不是“用了截位就是作弊”，而是：

- 只和全精度 exact 或未调参 prior 比，缺少等误差的窄精度 exact、rounding 和补偿基线。
- 仅凭 FP32 端口宣称完整公平，却未说明输出商位数、normal/finite 范围、异常值和舍入行为。
- 固定特化配置对比带 runtime mux/多级逻辑的配置，却不交代能力差异。
- 把均匀随机均值接近零当成最坏误差小或应用中不会累积；有符号输入还可能掩盖方向性偏差。
- 只报一个 MRED 数，而省略 RMSE、P99、边界、相关输入和真实工作负载；为一种指标调参却声称所有指标最优。
- 混用原作者 RTL、数学公式重建与本地优化版本的名称。

OADM 要保留说服力，核心应是可验证的局部平面硬件实现与 DIV/MUL 共享收益，而不是“截位本身新颖”或“普遍击败所有精确小内核”。共享比较仍必须包含强的独立窄精度 DIV+MUL 基线，并匹配模式、吞吐、精度和 wrapper。即便某些 MUL 点输给简单 baseline，也应报告，让贡献范围准确。
