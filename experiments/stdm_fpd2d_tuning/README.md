# STDM parameter tuning against FPD2D

Isolated experiment. Production RTL, paper and canonical results are not modified.

## Outcome

All 31 implementations completed ModelSim RTL/model checks on 343,790 vectors,
DC/PT, and gate checks on 21,043 vectors each. Sixteen exact implementation
ablation pairs also have identical actual RTL and gate outputs. All 14 baseline
PPA rows were read back from their original reports. See `audit.json`.

The useful current-L3 improvement is `stdm_tune_13_narrow`: Dx/Dy/W/B =
15/16/16/8, the original L3 coefficient table, and compact internal arithmetic.

| Metric | Existing L3 | L3 candidate |
|---|---:|---:|
| MRED (%) | 0.279426 | 0.228422 |
| RMSE | 0.00348154 | 0.00304423 |
| Area (um2) | 1865.52 | 1780.56 |
| Delay (ns) | 3.08149 | 2.87544 |
| Power (uW) | 83.4119 | 76.4530 |
| ADP (um2 ns) | 5748.58 | 5119.89 |

This reduces ADP by 10.94% while improving both average error metrics. L2 also
has a smaller improvement: `stdm_tune_02_narrow` lowers MRED and RMSE, and lowers
ADP by 0.95%, but its area is slightly higher. No strictly
accuracy-matched ADP improvement over the existing L0/L1 was found in this round.

No measured candidate beats the primary FPD2D 8x8 references in ADP while also
matching both MRED and RMSE:

| Reoptimized FPD2D reference | Reference ADP | Best accuracy-matched STDM ADP | STDM change |
|---|---:|---:|---:|
| 8x8 t17 | 1480.36 | 3373.25 | +127.87% |
| 8x8 t16 | 1706.15 | 4023.77 | +135.84% |
| 8x8 t15 | 1920.44 | 4094.95 | +113.23% |

These are local paper reconstructions, not author RTL, and this is a bounded
parameter/implementation search rather than a proof of a global optimum.
`RESULTS.md` contains every measured row and ablation; `INTERPRETATION.md`
connects the remaining gap to hierarchical area and critical-path reports.

## Protocol

1. Freeze the completed `../fpd2d` comparison and hash its evidence.
2. Jointly search independent residual drops Dx/Dy, plane drop W, coefficient
   fractional width B=5..11. Recalibrate coefficients for every configuration.
   Start at current drops +/-4 in steps of two; refine selected regions by one bit.
   Keep both MSE- and MRED-selected coefficient tables. No new approximation terms.
3. Implement finalists in the common FP32 wrapper. Compare original-width and
   narrowed arithmetic, then direct, binary shift-add and CSD coefficient products.
4. If necessary, test input masking and consistent input-width reduction, with
   coefficients recalibrated. Keep these distinct from original-input results.
5. Calibration seed 2026091601; independent screening seed 2026091602. Freeze
   finalists before evaluation on the existing FPD2D 200k random pairs. Check
   boundary grids, diagonal pairs, and safe signed/exponent cases separately.
6. Publish only completed RTL/model, DC, PT and gate-verified PPA rows. Use the
   existing ordinary hierarchical compile, common wrapper and 10 ns DC/PT flow.

Primary references are the stronger independently reconstructed FPD2D 8x8 MILP
tables at t=17/16/15. Printed-table results are retained as secondary references.
They are paper reconstructions, not author RTL. A strict win requires both MRED
and RMSE no worse, plus lower ADP. Sample maximum error is not a formal bound.

The screening cost proxy is a width estimate, never a PPA measurement. Numerical
no-drop diagnostics use Q23 arithmetic and need not be synthesis candidates.
The wrapper supports the same normalized-finite input/output domain as controls;
it does not implement the full IEEE special-value behavior.

## Reproduction

Run from the research directory using `.venv/bin/python`:

```sh
.venv/bin/python experiments/stdm_fpd2d_tuning/sweep.py
.venv/bin/python experiments/stdm_fpd2d_tuning/check_model.py
.venv/bin/python experiments/stdm_fpd2d_tuning/input_screen.py
.venv/bin/python experiments/stdm_fpd2d_tuning/extend.py
.venv/bin/python experiments/stdm_fpd2d_tuning/midpoint_extend.py
.venv/bin/python experiments/stdm_fpd2d_tuning/run.py all
.venv/bin/python experiments/stdm_fpd2d_tuning/collect.py
.venv/bin/python experiments/stdm_fpd2d_tuning/plot.py
.venv/bin/python experiments/stdm_fpd2d_tuning/audit.py
```

ModelSim, DC and PT require the licensed execution environment. The runner can
take `rtl`, `ppa`, or `gate` instead of `all`, followed by explicit top names.
Stages are skipped only when their source signatures match. No existing
production design is replaced. `RESULTS.md` is generated by the collector and
extended by the final audit; run them in that order to avoid duplicate sections.

`selected_round1.json` holds the 14 numerical finalists. `selected.json` also
includes seven compact-width equivalents, four constant-coefficient shift-add
variants, three input-mask/effective-drop ablation designs, and three exact
midpoint shift-add/table variants, for 31 measured designs in this campaign.
In a clean reproduction `extend.py` records the initial shortlist automatically.
